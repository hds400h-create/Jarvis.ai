📱 iPHONE 15 PRO MAX SETUP GUIDE
Step 1: Host on GitHub Pages & Add to Home Screen

Create a free GitHub repository → upload this file as index.html → Settings → Pages → Deploy from main. Open the HTTPS link in Safari → tap Share → Add to Home Screen.

සිංහල: GitHub Pages වල මේ file එක index.html විදිහට upload කරලා, ලැබෙන link එක Safari වලින් open කරලා Add to Home Screen දාගන්න.

Step 2: Build the JarvisBridge Apple Shortcut

Open iPhone Shortcuts app → tap + → name it exactly JarvisBridge and add:

  1. Split Text: Split Shortcut Input by Custom |
  2. Get Item from List: First Item → set variable Action
  3. Get Item from List: Item at Index 2 → set variable Payload
  4. If Action is CALL → Call Payload
  5. If Action is WHATSAPP → Open URLs https://wa.me/Payload
  6. If Action is NOTE → Create Note with Payload
  7. If Action is REMINDER → Add New Reminder Payload
  8. If Action is MAPS → Show Directions to Payload using Google Maps

සිංහල: Shortcuts app එකේ JarvisBridge හදලා Settings වල Execution Mode එක Apple Shortcut Bridge දැම්මම කෙලින්ම Call, Notes, Reminders සහ Maps auto වැඩ කරනවා.

Step 3: Map iPhone 15 Pro Max Action Button

Create a 1-step Shortcut called Launch Jarvis (Action: Open URLs → your GitHub Pages URL). Go to iPhone Settings → Action Button → Shortcut → Launch Jarvis.

සිංහල: දැන් phone එකේ පැත්තේ තියෙන Action Button එක ඔබපු ගමන් J.A.R.V.I.S. open වෙනවා!
