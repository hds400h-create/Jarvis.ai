📱 iPHONE 15 PRO MAX SETUP GUIDE
Step 1: Host on GitHub Pages & Add to Home Screen

Upload this file as index.html to GitHub Pages. Open your HTTPS link in Safari → tap Share → Add to Home Screen. Then paste your Gemini Key (AQ.... or AIza...) above and tap TEST API & VOICE.

සිංහල: GitHub Pages වල index.html විදිහට update කරලා, Safari Home Screen app එකෙන් open කරලා Gemini API Key එක save කරලා TEST API & VOICE ඔබන්න.

Step 2: Build the JarvisBridge Apple Shortcut

Open iPhone Shortcuts app → tap + → name it exactly JarvisBridge and add:

  1. Split Text: Split Shortcut Input by Custom |
  2. Get Item from List: First Item → set variable Action
  3. Get Item from List: Item at Index 2 → set variable Payload
  4. If Action is CALL → Call Payload
  5. If Action is WHATSAPP → Open URLs https://wa.me/Payload
  6. If Action is OPEN_APP → Open App (match Payload: Facebook, YouTube, TikTok, Instagram, WhatsApp, Comera, Botim, GoChat)
  7. If Action is NOTE → Create Note with Payload
  8. If Action is REMINDER → Add New Reminder Payload
  9. If Action is MAPS → Show Directions to Payload using Google Maps
Step 3: Map iPhone 15 Pro Max Action Button

Create a 1-step Shortcut called Launch Jarvis (Action: Open URLs → your GitHub Pages URL). Go to iPhone Settings → Action Button → Shortcut → Launch Jarvis.
