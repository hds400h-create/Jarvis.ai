📱 iPHONE 15 PRO MAX SETUP GUIDE
Step 1: GitHub Pages & Safari Home Screen

Paste this file into index.html on GitHub Pages. Open your HTTPS link in Safari → Share → Add to Home Screen. Save your Gemini Key (AQ.... or AIza...) above and tap TEST API & VOICE to auto-discover live models.

සිංහල: GitHub Pages වල index.html එක update කරලා, Home Screen app එක close කරලා ආයෙ open කරලා ⚙️ iOS Setup → TEST API & VOICE ඔබන්න — එතකොට ඔයාගේ account එකට වැඩ කරන live model එක auto තෝරගන්නවා.

Step 2: Build JarvisBridge Apple Shortcut

Open Shortcuts → tap + → rename to JarvisBridge and add:

  1. Split Text: Split Shortcut Input by Custom |
  2. Get Item from List: First Item → Action
  3. Get Item from List: Item at Index 2 → Payload
  4. If Action is CALL → Call Payload
  5. If Action is WHATSAPP → Open URLs https://wa.me/Payload
  6. If Action is APP → Open App (Facebook, YouTube, TikTok, Instagram, WhatsApp, Comera, Botim, GoChat)
  7. If Action is NOTE → Create Note with Payload
  8. If Action is REMINDER → Add New Reminder Payload
  9. If Action is MAPS → Show Directions to Payload in Google Maps
Step 3: iPhone 15 Pro Max Action Button

Create a Shortcut named Launch Jarvis (Action: Open URLs → your GitHub Pages URL). Then go to Settings → Action Button → Shortcut → Launch Jarvis.

සිංහල: Shortcuts වල Launch Jarvis හදලා iPhone Settings → Action Button එකට set කරගන්න.
